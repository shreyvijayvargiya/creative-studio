## Email ping-pong slows every engagement

Traditional signing flows look like this:

1. Export PDF from your tool
2. Upload to a third-party signer
3. Email the client a link
4. Chase reminders manually
5. Download the signed copy back into storage

Each step is small. Together they fragment the client experience.

## Embedded signing inside your workspace

DocuSeal runs inside Finance CRM so clients never leave your environment:

- Branded signing screen
- Automatic save to your document library
- Optional PIN when sharing externally

### Checklist before you send

- [ ] Budget figures reconciled in the grid
- [ ] Taxpayer details complete
- [ ] PDF preview reviewed
- [ ] Client email confirmed

## Security practitioners care about

| Concern | How we handle it |
| --- | --- |
| Storage | Private Supabase workspace per account |
| Sharing | Optional PIN on view links |
| Backup | Per-user Google Drive OAuth (your quota) |
| Audit trail | Signed PDF stored with created timestamp |
